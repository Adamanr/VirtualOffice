# Virtual Office

Браузерный 3D-офис: персонажи, пространственный голос/видео (LiveKit), демонстрация экрана и PDF на больших экранах.

- `client/` — Vite + React + TS + React Three Fiber
- `server/` — Phoenix (API + Channels + Presence)
- `infra/` — docker-compose, LiveKit, Caddy
- `shared/` — `level.json`, `protocol.json` (+ сгенерированный `protocol.gen.ts`)
