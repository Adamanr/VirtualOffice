# Office models and textures

* Furniture, plants, clock, fire alarm, microwave, desk stationery, floor / wall /
  ceiling textures and the `env.hdr` environment: **Poly Haven** (https://polyhaven.com),
  CC0 — public domain, no attribution required.
* Swivel chairs, workstations, cubicles, filing cabinets, bins, water cooler,
  vending machine, copier, fridge, coffee machine, meeting table, kitchen counter,
  reception desk: modelled for this project by `shared/tools/office/build.py`
  (same license as the project), some using Poly Haven textures.

Rebuild: `shared/tools/office/fetch.py` → `build.py` (Blender) → `optimize.sh`
→ `textures.py` (see the header of each script).
